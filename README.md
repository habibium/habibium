## Open source

- [hodis](https://github.com/habibium/hodis): web search from the terminal, for people and AI agents. A Rust CLI and MCP server, [on crates.io](https://crates.io/crates/hodis).
- [Whatomato](https://github.com/habibium/whatomato): schedules WhatsApp messages to go out once, on a cron expression, on the second Tuesday of every month, or at sunset. Rust and React in one Docker image; self-host it or use [the hosted one](https://whatomato.habibium.com).

- [Bun SQL vs Drizzle](https://habibium.com/blog/bun-sql-vs-drizzle): a benchmark of Bun's native SQL driver against Drizzle ORM on PostgreSQL 18, with [the code](https://github.com/habibium/bun-sql-drizzle-benchmark).
